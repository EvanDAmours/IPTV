# IPTV Player — hosted iPhone copy (GitHub Pages)

This branch (`gh-pages`) is the **hosted copy** of the player, served by GitHub Pages at
**https://evandamours.github.io/IPTV/** — open it in Safari on iPhone, then Share → *Add to Home Screen*.

- `index.html` — the player, with iPhone tweaks (bottom tab bar, swipe on the video to change channel,
  AirPlay, home-screen app icon and manifest).
- The original desktop file lives on `main` as `iptv-player.html` and is **not** changed by this branch.

Your login and favorites are saved in each browser separately. To bring your setup over, use
*Backup & restore* on the computer, then **Sign in with a backup file** on the iPhone.
